\# Quickload quicksave mod



This was a test project to teach me how to mod code into Unity games.



It works by patching the Savior Object (The base save manager from the game) to add new functionality that replicates the save and load mechanisms from the base game. Storing the same variables in the same format than the original game. This process is very efficient since the base game is designed to save the game every few frames to avoid cheating.



\# Keybinds:

* F8 - Quick Save
* F10 - Quick Load
* F1 - Toggle Keybinds



Claude was used to generate the style boilerplate of the in game tooltip since I have no experience with Unity UI.
